### 🚀 Featured Projects

#### 🤖 [Chat2Anything](https://github.com/CosmicResearchCenter/chat2anything)
**Chat2Anything is a powerful Retrieval-Augmented Generation (RAG) system that allows users to interact with various data sources through natural language. This project integrates advanced vector search and large language model technologies, supports the import of multiple document formats, and provides you with intelligent and efficient knowledge retrieval and question-answering services.**

Main Features
- 🔍 Intelligent document retrieval and Q&A
- 🌐 Supports multiple LLM providers (OpenAI, Zhipu, OneAPI, etc.)
- 📊 Efficient vector storage and retrieval systems (Milvus, Elasticsearch)
- 📁 Supports import of multiple document formats
- 💬 Natural language interaction interface
- 🛠️ Simple and easy-to-use Docker deployment solution

#### 🤖 [VocabVerse](https://github.com/MarkYangKp/VocabVerse)
**VocabVerse is an English vocabulary learning tool based on Large Language Models (LLMs). It generates English articles containing user-specified words through LLMs, helping learners understand and memorize English words in context.**

**Core Features:**

- **Intelligent Article Generation**: Input a list of words, and AI will generate a coherent English article containing these words
- **Article difficulty customization**: Different difficulty levels (postgraduate entrance exams, CET-4 and CET-6, high school, etc.) and article types (argumentative essays, expository essays, novels, etc.) can be selected
- **Translation and Explanation**: Automatically provide article translation and detailed word explanations
- **Exercise Generation**: Generate relevant exercises based on the content of the article to help deepen understanding
- **History Record Management**: Browse, view, and manage previous learning records

#### 🎓 [ZhengFang Education System Course Selection Script](https://github.com/MarkYangKp/ZhengFangJY)
**Automated course selection for university system**
> Efficient script to handle course registration in ZhengFang education system

- **Tech Stack**: Python, Requests, BeautifulSoup
- **Features**: High concurrency handling, automatic retry mechanism, user-friendly configuration
- **Status**: 🟡 Maintained
